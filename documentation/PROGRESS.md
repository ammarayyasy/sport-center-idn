## 💡 Teknologi yang Digunakan
1. **HTML5 Semantik**: Struktur dokumen ramah SEO dan screen reader.
2. **Tailwind CSS (CDN)**: Utility-first CSS styling dengan skema warna atletis modern tanpa perlu kompilasi rumit.
3. **Google Fonts (Plus Jakarta Sans)**: Tipografi modern dan mudah dibaca.
4. **Lucide Icons**: Ikon vektor SVG yang tajam dan ringan.
5. **Vanilla JavaScript**: Filter kategori lapangan, kalkulator perhitungan harga sewa instan, dan modal dialog simulasi booking.

---

## 🚀 Cara Menjalankan Secara Lokal
1. Buka folder proyek `sport-center-idn`.
2. Klik ganda file `index.html` pada File Explorer untuk langsung membukanya di browser (Chrome / Edge / Firefox).
3. Atau gunakan ekstensi **Live Server** di VS Code untuk reload otomatis saat pengeditan.
